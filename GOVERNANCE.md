# Governance

Orako Core uses a maintainer-led governance model.

Palmthree LLC is the project steward and appoints maintainers. Maintainers review
changes, manage releases, enforce community policies, and decide the product
roadmap. Decisions favor security, interoperability, self-host reliability, and
long-term maintainability.

Substantial changes should begin with a GitHub issue or discussion. Maintainers
seek consensus where practical; the project steward makes the final decision
when consensus is not reached.

Contributor status is earned through sustained, constructive participation.
Repository permissions may be changed or removed to protect the project.
