# Security Policy

## Supported versions

Security fixes are provided for the latest release and the `main` branch.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** flow in the Security tab of this
repository. Do not open a public issue or discussion.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. You should receive an acknowledgement within three business days.
We will coordinate disclosure after a fix is available.

Never include production credentials, personal data, or customer content in a
report.
