# Support

- Use [GitHub Discussions](https://github.com/orako-io/core/discussions) for
  setup questions, ideas, and community help.
- Use [GitHub Issues](https://github.com/orako-io/core/issues) for reproducible
  bugs and scoped feature requests.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Maintainers do not guarantee response times for community support. Commercial
support is available separately through [orako.io](https://orako.io).
